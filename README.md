# Zenv Gifts — 50 product download pack

[Download the complete store pack](https://github.com/fratbeats930-lab/zenvgifts/raw/refs/heads/zenv-gifts-download/zenv-gifts-50-product-store-pack.zip)

Contains 50 original sample products with unique generated photos, detailed descriptions and editable INR prices (699–4,999 rupees). Extract the outer pack. Upload the inner theme ZIP in Shopify Themes, then import one product CSV separately in Shopify Products.

- `zenv-gifts-50-products-active.csv`: active products published to the Online Store after import.
- `zenv-gifts-50-products-draft.csv`: unpublished drafts for review instead.
- `images/`: all 50 individual product photos; CSV image URLs point to these files for Shopify to download.
- `zenv-gifts-50-product-catalogue.html`: visual catalogue to open after extracting the store pack.
- `ZENV-GIFTS-START-HERE.txt`: Hindi setup steps.

The theme ZIP alone does not create products. Images, descriptions, names and prices can be changed from Shopify after CSV import. This download branch hosts delivery files; live payment, accounts, shipping and fulfillment remain Shopify store settings.
